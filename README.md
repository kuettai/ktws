# ktws - hands-on workshops

Self-paced and instructor-led workshops, each with guides, starter code, reference solutions and
deployment templates. Every workshop lives in its own folder, named `{CATEGORY}-{###}-{TITLE}`.

| Workshop | Level | Duration | Status |
|---|---|---|---|
| [AWS-001 Agentic from Scratch](AWS-001-AgenticFromScratch/README.md) - build, secure and deploy MCP servers, then AI agents, on AWS | Beginner to intermediate (SQL background, no Python needed) | 3 days | Day 1 tested end to end; Days 2-3 preview |

## Using a workshop

Open its folder and start with its README. Each workshop's guides are also published as a website
at [kuettai.github.io/ktws](https://kuettai.github.io/ktws/).

## Disclaimer

These are personal sample workshops, not official AWS training. They deploy real, billable AWS
resources: use a sandbox account, and delete the stacks when you finish.
